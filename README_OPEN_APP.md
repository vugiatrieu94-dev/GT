# Mở app OpsFlow

## Mở nhanh

1. Mở file **`index.html`**
2. Chọn **cửa hàng / ngày / ca / bộ phận**
3. Nhập checklist vận hành
4. Bấm **`Đồng bộ`** để lưu vào Lark Base
5. Bấm **`Gửi Lark`** để gửi báo cáo vào group

## App hiện làm được gì

- Nhập checklist theo ca và bộ phận
- Tạo báo cáo vận hành nhanh
- Đồng bộ dữ liệu sang Lark Base
- Gửi báo cáo vào group Lark bằng webhook
- Hỏi AI nội bộ theo knowledge đã tích hợp

## Lưu ý khi dùng

- Để **AI / Đồng bộ / Gửi Lark** hoạt động thật, backend cần đang chạy.
- Nếu chỉ mở file HTML mà chưa chạy backend, bạn vẫn xem và thao tác giao diện được, nhưng các chức năng gọi API sẽ không phản hồi.
- File này là **điểm vào app** để mở và demo nhanh.
